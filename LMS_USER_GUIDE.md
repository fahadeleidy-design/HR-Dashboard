# Learning Management System (LMS) - User Guide

## Overview

The comprehensive Learning Management System (LMS) provides enterprise-grade learning and development capabilities, enabling organizations to deliver, track, and analyze training programs across their workforce.

## Key Features

### 1. Course Catalog
**Comprehensive course library with advanced search and filtering**

#### Features:
- **Rich Course Listings**: Detailed course information with thumbnails, descriptions, and instructor details
- **Smart Search**: Full-text search across course titles and descriptions
- **Advanced Filtering**: Filter by category, difficulty level, and format
- **Course Levels**: Beginner, Intermediate, Advanced, Expert
- **Course Formats**: Self-paced, Instructor-led, Blended, Workshop, Webinar
- **Ratings & Reviews**: 5-star rating system with detailed course reviews
- **Certificate Awards**: Courses can award certificates upon completion
- **CPD/CPE Credits**: Track professional development credits
- **Enrollment Management**: Track enrollments and completions

#### Course Categories:
- Leadership & Management
- Technical Skills
- Compliance & Safety
- Soft Skills
- Finance & Accounting
- Sales & Marketing
- HR & Talent Development
- Operations & Process

#### How to Use:
1. Navigate to **Training** → **Course Catalog** tab
2. Use the search bar to find specific courses
3. Filter by category, level, or format
4. Click on a course to view details
5. Click "Enroll Now" to start learning

### 2. Learning Paths
**Structured learning journeys with sequential course progression**

#### Features:
- **Structured Sequences**: Courses organized in logical progression
- **Prerequisites**: Enforce course order and dependencies
- **Progress Tracking**: Visual progress indicators
- **Milestone Tracking**: Track completed vs total courses
- **Certificate Awards**: Earn certificates upon path completion
- **Flexible Completion**: Self-paced or time-bound paths
- **Enrollments**: Track who is enrolled in each path

#### Learning Path Components:
- **Path Code**: Unique identifier
- **Difficulty Level**: Overall path difficulty
- **Estimated Duration**: Total hours to complete
- **Completion Criteria**: Requirements to finish the path
- **Course Sequence**: Ordered list of courses
- **Mandatory vs Optional**: Some courses may be optional

#### How to Use:
1. Navigate to **Training** → **Learning Paths** tab
2. Browse available learning paths
3. Click "Start Path" to enroll
4. Complete courses in sequence
5. Track progress in "My Progress" section
6. Earn certificate upon completion

### 3. Compliance Training
**Mandatory training tracking with expiry management**

#### Features:
- **Mandatory Requirements**: Company-wide or role-based compliance
- **Recurring Training**: Automatic renewal requirements
- **Expiry Tracking**: Certificate expiration dates
- **Due Date Management**: Track training deadlines
- **Grace Periods**: Configurable grace periods
- **Status Tracking**: Not Started, In Progress, Completed, Overdue, Expired
- **Automated Reminders**: Email notifications for due/expiring training
- **Regulatory Compliance**: Link to regulatory bodies and references
- **Assignment Logic**: Auto-assign based on department, role, or location

#### Compliance Status Types:
- **Not Started**: Training assigned but not begun
- **In Progress**: Currently taking the training
- **Completed**: Successfully finished
- **Expired**: Certificate has expired
- **Overdue**: Past due date without completion

#### Dashboard Metrics:
- Total compliance requirements
- Completed count
- Pending assignments
- Overdue training
- Expiring soon (within 30 days)

#### How to Use:
1. Navigate to **Training** → **Compliance** tab
2. View all assigned compliance training
3. Filter by status (All, Pending, Completed, Overdue, Expiring Soon)
4. Click "Start Training" on any requirement
5. Complete before due date
6. Monitor certificate expiry dates
7. Re-certify before expiration

### 4. Enhanced Quiz Engine
**Multi-format assessments with detailed analytics**

#### Question Types Supported:
- **Multiple Choice**: Single correct answer from options
- **Multiple Select**: Multiple correct answers
- **True/False**: Binary choice questions
- **Short Answer**: Text-based responses
- **Essay**: Long-form written responses
- **Fill in the Blank**: Complete missing words
- **Matching**: Match items from two lists
- **Ordering**: Arrange items in correct sequence
- **Hotspot**: Click on areas of an image

#### Assessment Features:
- **Question Bank**: Centralized repository of reusable questions
- **Random Selection**: Randomize questions and options
- **Time Limits**: Configurable assessment duration
- **Multiple Attempts**: Allow retakes with cooldown periods
- **Passing Scores**: Configurable pass/fail thresholds
- **Instant Feedback**: Show correct answers after submission
- **Manual Grading**: Support for essay/open-ended questions
- **Detailed Scoring**: Track points per question
- **Attempt History**: Complete attempt tracking

#### Assessment Templates:
- Reusable assessment configurations
- Consistent testing standards
- Easy deployment across courses
- Version control and updates

#### How to Use:
1. Access assessments within course modules
2. Read instructions and time limit
3. Answer all questions
4. Submit for grading
5. Review results and feedback
6. Retake if allowed and needed

### 5. External Content Integration
**Seamlessly integrate external learning resources**

#### Supported Platforms:
- **YouTube**: Embed video content
- **Vimeo**: Professional video hosting
- **LinkedIn Learning**: Professional courses
- **Udemy**: Course marketplace integration
- **Coursera**: University-level courses
- **SCORM Packages**: Industry-standard e-learning
- **Custom URLs**: Any external learning resource

#### Integration Features:
- **Embed Support**: Display content within platform
- **Completion Tracking**: Track external content completion
- **Webhook Integration**: Receive completion notifications
- **SSO Support**: Single sign-on where available
- **API Connections**: Automated sync and updates
- **Metadata Sync**: Keep course info up-to-date

#### Content Source Management:
- Configure API keys and credentials
- Set up OAuth authentication
- Enable auto-sync schedules
- Monitor sync status
- Manage multiple sources

#### How to Use:
1. HR/Admin: Configure external content sources
2. Link external content to courses
3. Learners access through course catalog
4. Content opens in embedded player or new tab
5. Completion tracked automatically
6. Progress synced back to LMS

### 6. Learning Analytics
**Comprehensive insights and performance metrics**

#### Key Metrics:
- **Active Learners**: Currently engaged users
- **Total Courses**: Available course count
- **Completion Rate**: Percentage of started courses completed
- **Average Score**: Mean assessment performance
- **Learning Hours**: Total time spent learning
- **Certificates Issued**: Count of earned certificates

#### Analytics Dashboards:
1. **Enrollment Trends**: Track enrollments and completions over time
2. **Category Distribution**: Course enrollments by category
3. **Top Courses**: Most popular courses by enrollment
4. **Performance Metrics**: Assessment scores and completion rates
5. **Time Analytics**: Learning hours and engagement patterns
6. **Compliance Metrics**: Compliance completion rates

#### Reports Available:
- Monthly learning summaries
- Department-wise analytics
- Role-based learning patterns
- Individual learner progress
- Compliance status reports
- Course effectiveness metrics

#### Data Visualization:
- Line charts for trends
- Bar charts for comparisons
- Pie charts for distributions
- Progress indicators
- Heat maps for engagement

#### How to Use:
1. Navigate to **Training** → **Analytics** tab (Admin/HR only)
2. View real-time dashboard metrics
3. Analyze enrollment and completion trends
4. Identify top-performing courses
5. Monitor compliance rates
6. Export reports for stakeholders

### 7. Learning Recommendations
**AI-powered personalized course suggestions**

#### Recommendation Types:
- **Role-based**: Courses aligned with job role
- **History-based**: Based on previous learning
- **Peer-based**: What similar employees are taking
- **Manager-suggested**: Direct manager recommendations
- **Skill Gap**: Based on performance assessments

#### Features:
- Confidence scoring (0-100%)
- Reasoning explanation
- Dismiss unwanted suggestions
- One-click enrollment
- Refresh recommendations

### 8. Course Ratings & Reviews
**Community-driven course feedback**

#### Review Components:

- **Detailed Review**: Full feedback
- **Category Ratings**:

#### Moderation:
- Admin approval required (optional)
- Edit/delete inappropriate content

#### Certificate Types:

## Database Schema

### Core Tables

#### course_catalog
Main course information repository
- Course code, title, descriptions
- Category, level, format
- Duration and language
- Instructor information
- Prerequisites
- Enrollment settings
- Pricing (if applicable)
- Certification details
- Publishing status
- Analytics (enrollments, completions, ratings)

#### course_categories
Hierarchical course organization
- Category name and description
- Parent category (for sub-categories)
- Display order
- Icon

#### learning_paths
Structured learning journeys
- Path code and title
- Difficulty level
- Estimated duration
- Completion criteria
- Certificate awards
- Analytics

#### learning_path_courses
Courses within paths
- Sequence order
- Mandatory vs optional
- Prerequisites within path
- Unlock conditions

#### learning_path_enrollments
User enrollments in paths
- Enrollment date
- Target completion date
- Progress tracking
- Certificate issuance

#### compliance_requirements
Mandatory training rules
- Requirement code and title
- Type (mandatory, role-based, location-based)
- Associated course/path
- Recurrence frequency
- Applicability rules
- Pass score requirements
- Effective dates

#### compliance_assignments
Individual compliance tracking
- Assigned employee
- Due date
- Completion status
- Certificate expiry
- Reminder tracking

#### assessment_question_bank
Centralized questions
- Question text and type
- Answer options
- Correct answers
- Points and difficulty
- Explanation and media
- Usage statistics

#### assessment_templates
Reusable assessments
- Configuration settings
- Passing score
- Time limit
- Question selection rules
- Attempt limits
- Feedback options

#### assessment_attempts
Individual test attempts
- Employee and assessment
- Responses and scoring
- Time spent
- Pass/fail status
- Grading information

#### external_content_sources
Integration configurations
- Source name and type
- API credentials
- OAuth tokens
- Sync settings

#### external_content_items
Linked external resources
- External ID and URL
- Content details
- Embed information
- Completion tracking

#### learning_analytics
Aggregated metrics
- Date-based snapshots
- Department/role segments
- Enrollment and completion stats
- Average scores and hours
- Compliance rates

#### learner_activity_log
Detailed activity tracking
- Employee and activity type
- Course and module references
- Duration and completion
- Device and location

#### course_ratings_reviews
User feedback
- Rating (1-5 stars)
- Review title and text
- Category-specific ratings
- Moderation status
- Helpfulness votes

#### learning_recommendations
Personalized suggestions
- Employee and course
- Recommendation type
- Confidence score
- Reasoning

## Best Practices

### For Administrators

1. **Course Organization**
   - Use clear, descriptive titles
   - Categorize courses appropriately
   - Add comprehensive descriptions
   - Include learning objectives
   - Set realistic duration estimates

2. **Learning Path Design**
   - Create logical course sequences
   - Set appropriate prerequisites
   - Define clear completion criteria
   - Balance mandatory and optional courses
   - Test paths before publishing

3. **Compliance Management**
   - Set reasonable deadlines
   - Configure reminder schedules
   - Define grace periods
   - Track regulatory changes
   - Maintain up-to-date requirements

4. **Assessment Creation**
   - Use varied question types
   - Set fair passing scores
   - Provide clear instructions
   - Allow reasonable time limits
   - Give constructive feedback

5. **Analytics Usage**
   - Review metrics weekly
   - Identify low-performing courses
   - Track completion trends
   - Monitor compliance rates
   - Act on insights

### For Learners

1. **Course Selection**
   - Review course objectives
   - Check prerequisites
   - Read reviews and ratings
   - Verify certificate availability
   - Note time commitment

2. **Learning Strategy**
   - Complete courses sequentially in paths
   - Take notes during courses
   - Attempt quizzes seriously
   - Review feedback carefully
   - Ask questions when needed

3. **Compliance Adherence**
   - Check assigned training regularly
   - Complete before deadlines
   - Monitor certificate expiry
   - Re-certify proactively
   - Keep records of certificates

4. **Engagement**
   - Rate and review courses
   - Share feedback constructively
   - Recommend courses to peers
   - Participate in discussions
   - Track personal progress

## Troubleshooting

### Common Issues

**Course not loading**
- Check internet connection
- Clear browser cache
- Try different browser
- Contact support with course ID

**Assessment not submitting**
- Ensure all questions answered
- Check time remaining
- Verify internet connection
- Save draft if available

**Certificate not generating**
- Confirm course completion
- Check assessment pass status
- Allow processing time
- Contact HR if delayed

**Compliance assignment missing**
- Refresh assignments page
- Check with HR/Admin
- Verify role/department
- Review effective dates
