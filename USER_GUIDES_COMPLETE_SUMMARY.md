## Documentation Quality Features

### ✅ Task-Oriented Instructions
Every guide focuses on **what users need to accomplish**:
- "How to request leave" not "About the leave module"
- "How to submit expenses" not "Expense system overview"
- Clear, actionable steps
- Goal-focused content

### ✅ Step-by-Step Procedures
All tasks include:
1. **Task Name**: Clear description
2. **Time Estimate**: How long it takes
3. **Prerequisites**: What you need first
4. **Location**: Where in system
5. **Detailed Steps**: Numbered, sequential
6. **System Response**: What happens after each step
7. **Success Indicator**: How to confirm completion
8. **Alternative Flows**: What if something goes wrong
9. **Tips**: Best practices and shortcuts

Example Format:
```
Task: Submit Leave Request
Time: 3-5 minutes
Prerequisites: Sufficient leave balance
Location: Leave → Request Leave

Steps:
1. Navigate to Leave module
   → System displays: Leave dashboard

2. Click "Request Leave" button
   → System displays: Leave request form

3. Fill required fields:
   - Leave Type: Annual Leave
   - Start Date: March 15, 2026
   - End Date: March 20, 2026
   - Reason: Family vacation
   → System calculates: 6 days, balance after: 15 days

4. Click "Submit Request"
   → System validates and submits

5. Confirmation displayed
   ✅ Success: Request submitted for approval

💡 Tips:
- Request 3 days in advance
- Check team calendar first
- Attach documents if required
```

**If not resolved:**
1. User uses support ticket template from Troubleshooting guide
2. Includes all required information
3. Submits to IT Helpdesk
